## User Stories Completed

- As a customer, I can view the live restaurant menu and check real-time dish availability before ordering.
- As a customer, I can log in securely using Google authentication.
- As a customer, I can place an order directly from the app and track its status.
- As a waiter/staff member, I can view and manage incoming orders from a central dashboard.
- As kitchen staff, I can receive orders instantly without relying on verbal communication.
- As a restaurant manager, I can view billing and order details in one unified system.
- As a restaurant manager, I can access operational analytics and insights on restaurant performance.

---

## AI Usage in the App

- **Gemini API** is integrated into the backend to power AI-driven features within the platform, such as generating intelligent insights/responses as part of the restaurant workflow.
- **Emergent** (AI-assisted coding platform) was used to build and scaffold the full-stack application (frontend + backend) from natural language prompts.
